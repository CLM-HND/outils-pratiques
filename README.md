# Outils pratiques

Petits outils en ligne gratuits, 100 % dans le navigateur. Site statique déployé par Vercel à chaque push sur `main`.

## Ajouter un outil

1. Créer `outils/<slug>/index.html` (s'appuie sur `/assets/style.css`, titre et description SEO en français).
2. Ajouter l'outil dans `tools.json` (slug, titre, description, date).
3. Ajouter l'URL dans `sitemap.xml`.
